## About Me

Senior Software Engineer / SDET with 6+ years of experience building backend systems, internal platforms, automation tooling, and production-like test infrastructure.

I work at the intersection of **software engineering, test automation, platform engineering, and DevOps**, focusing on improving system reliability, engineering efficiency, and software delivery.

My experience spans:

* **Backend Engineering** — Python, Django, Flask, FastAPI, NestJS, TypeScript
* **Full-Stack Internal Tooling** — React, Next.js, PostgreSQL, Redis
* **Test Engineering** — system, integration, end-to-end, performance, and load testing
* **CI/CD & Release Engineering** — automated validation, deployment pipelines, release readiness
* **Test Infrastructure** — QA and Pre-Production environment architecture and reliability
* **Infrastructure Automation** — Terraform, Ansible, AWX, Rundeck, Python, Bash
* **Containers & Platforms** — Kubernetes, Docker, OpenStack, VMware
* **Observability** — Grafana, Prometheus, Elasticsearch, Logstash, Kibana

I enjoy solving engineering problems where **software development, automation, infrastructure, and testing overlap**.
